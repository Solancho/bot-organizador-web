Política de privacidad

Bot organizador · Última actualización: 21 de octubre de 2026

Uso personal

Bot organizador es una herramienta de uso personal. Solo accede a las cuentas de su autor, quien la autoriza expresamente.

Datos a los que accede

  • Google Calendar: crea, actualiza y elimina únicamente los eventos que el propio bot creó.
  • Canvas y correo institucional: solo lectura de fechas de tareas, evaluaciones, reuniones e invitaciones.

Uso y almacenamiento

Los datos se usan exclusivamente para crear eventos en el calendario del mismo usuario. No se venden, no se comparten con terceros y no se usan con fines publicitarios. Las credenciales de acceso se guardan cifradas y pueden revocarse en cualquier momento desde la configuración de la cuenta de Google.

Uso de datos de las API de Google

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
